# Omit Mac App Store 商品页交付包

状态：PO 审核草稿  
任务：`TASK-STORE-001`  
更新：2026-08-27

本目录是 Omit 首次 Mac App Store 上架的文案与截图制作入口。内容只描述 App Store 发行版本，不包含 Trash、Full Disk Access、GitHub Direct、真实温度或尚未交付的系统 Thermal State。

## 审核顺序

1. [METADATA.md](METADATA.md)：审核简体中文、英文、日文的商店字段与字符限制。
2. [SCREENSHOT_STORYBOARD.md](SCREENSHOT_STORYBOARD.md)：审核三张首发截图的顺序、状态、文案与取景。
3. [ASSET_CHECKLIST.md](ASSET_CHECKLIST.md)：截图制作和交付时逐项勾选。

## 当前建议

- 首发名称三种语言统一使用 `Omit`，让本地化重点落在副标题、推广文本与描述。
- 首发截图采用三张：Light Dashboard、Dark Dashboard、Appearance Settings。
- 系统 Thermal State 的文案与第 4 张截图只保留为条件草稿，当前标记 `BLOCKED`，不得上传或混入首发素材。
- Settings 截图需等待 App Store 发行变体彻底移除 Trash 设置项后再制作。

## 明确不在本包中填写

- Privacy Policy URL
- Support URL
- Marketing URL
- 法律、版权主体或联系地址
- App Store Connect 记录、价格、分类、年龄分级与审核联系人

这些字段必须由 PO 提供真实信息；本任务不虚构占位地址，也不执行上传。
